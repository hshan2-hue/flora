📖 1. 实证开篇：波兰看守中心的九日抗争与话语抹除

2019年5月，波兰受监管外国人中心（SOdC）的9份官方边防警卫备忘录，记录了一名年轻女性在拘留环境下的急性心理危机。通过利用 Voyant Tools 对 1,246 个波兰语词汇进行的计算分析，研究揭示了制度性文本如何通过特定的词汇机制抹除当事人的主体性。

DAY 1 · 5月17日
吐出牙膏在地上写下“伊拉克”，拆开床垫套并藏匿金属勺。
DAY 3 & 4 · 5月18–19日
捡拾废弃残羹，踢打隔离闸门，在窗户上用牙膏涂写“玻璃仇恨”。
DAY 8 & 9 · 5月22–23日
搜集野生蘑菇与烟蒂，将果酱涂抹在墙面，最终被移送至15分钟监视的禁闭室。
波兰看守中心隔离室的建筑格局（来源：Chwieduk, 2022）
“在这 9 份官方备忘录中，通篇未曾出现过她的真实名字，而是被统一抽象为‘被拘留者’（umieszczona）。通过 Voyant 的搭配词网络分析，她的肢体与语言抗争在统计学上被高频绑定至‘垃圾’与‘卫生’范畴，精神层面的创伤表达被系统性稀释成了清洁管理问题。”

📌 2. 工具定位：什么是 Voyant Tools？

Voyant Tools 是一款面向人文学者的免编程、交互式数字文本分析与阅读环境。它无需安装 Python 或 R 编译环境，通过预构建的联动小部件，让学者能够穿梭于海量文献的整体轮廓与细微上下文之间。

  • 远读与细读的同步连接：词云（Cirrus）与趋势图（Trends）提供宏观词频概览，而阅读器（Reader）与语境索引（Contexts）则即时定位具体词句。
  • 多部件联动机制：在图表中点击任意词语，其他 4 个面板会毫秒级联动响应，保持探索的一致性。
  • 多语言与跨国语料支持：内建丰富的分词与字符编码支持，适配英语、波兰语、法语及中文等多语种文献。

⚙️ 3. 技术底座（Behind the Interface）

Voyant Tools 基于成熟稳定的开源技术栈构建。其后端依赖 Java 与 Apache Lucene 搜索引擎，能够在毫秒级内完成文档的解析与倒排索引构建；前端结合 JavaScript、Ext JS 与 D3.js 图表库，提供流畅的数据可视化与多图表动态联动体验。

🏛️ 4. 团队、主持机构与开源资源

该项目由阿尔伯塔大学 Geoffrey Rockwell 教授与麦吉尔大学已故教授 Stéfan Sinclair 共同创立，目前由阿尔伯塔大学联合加拿大数字研究联盟（LINCS Project）长期主持维护。
